# Map rules for this DV2

1. Use at least three genuinely different map idioms, not three copies of the same point map.
2. Use an appropriate projection. For these Australia-wide regional maps, the starter uses `conicEqualArea`.
3. Do not use Web Mercator merely because it is familiar. It is more suitable for small zoomed areas than for area-sensitive regional/world comparison.
4. Explain what every map mark means: recorded occurrence, BIA polygon, state value, or marine-park boundary.
5. ALA occurrence density must never be labelled as animal population density.
6. BIA polygons must never be labelled as complete species range.
7. Do not claim the marine-park overlay is a calculated protection percentage unless you actually perform polygon intersections and area calculations.
8. Keep map files small enough for a fast GitHub Pages load; use generalised/simplified boundaries where appropriate.
9. Use consistent legends, colour meanings, projection and cartographic hierarchy across the page.
10. Cite the exact datasets and URLs used.
